买房或装修时，很多人会被劝“看看房子朝向合不合自己”。这类建议大多基于**八宅**，一个把住宅分成八方、四吉四凶的风水流派。本文按公开来源的记载，介绍八宅的说法。这是供参考的文化知识，并不承诺财运或健康。

## 坐与向：房子的两面

每座房子都有相对的两面。**向**是正面朝外的方向。**坐**是房子背面，与向相反。房子朝南，就是坐北。

据 <cite lang="en">Feng Shui Web</cite>、<cite lang="en">Absolutely Feng Shui</cite> 和 <cite lang="en">Feng Shui Today</cite> 等介绍八宅的来源，房子的“宅”名按**坐方**而定，对应八卦中的一卦：

| 坐 | 宅 |
|---|---|
| 北 | 坎 |
| 南 | 离 |
| 东 | 震 |
| 东南 | 巽 |
| 西北 | 乾 |
| 西南 | 坤 |
| 东北 | 艮 |
| 西 | 兑 |

例如：房子朝南即坐北，是**坎宅**。

有一点容易混淆：越南的许多大众网页讲的是“房屋朝向”（正面方向），却没有说明指的是坐还是向。查表时，最好先看清这张表用的是坐还是向，再去对照。

## 东四宅与西四宅

八宅分为两组：

- **东四宅：**坎、离、震、巽（坐北、南、东、东南）。
- **西四宅：**乾、坤、艮、兑（坐西北、西南、东北、西）。

人也按**卦数**（命卦）分为两组，由出生年份和性别算出。卦数 1、3、4、9 属东四命；2、6、7、8 属西四命。各来源通常建议人住同组的房子。不过，<cite lang="en">Absolutely Feng Shui</cite> 明确写道这一点“并非强制”。

## 八方：四吉四凶

在每种宅中，房子周围的八个方位各配一颗星：

- **四吉方：**生气、天医、延年、伏位。
- **四凶方：**祸害、五鬼、六煞、绝命。

伏位总是在正坐方。以坎宅（坐北）为例，搜狐上的文章等中文资料记载：生气在东南，天医在东，延年在南，伏位在北；祸害在西，五鬼在东北，六煞在西北，绝命在西南。

## 书中常见的布局建议

以下是至少两份公开来源都提到的建议。在来源意见不一的地方，本文把两方都列出。

- **大门：**设在或朝向一个吉方，通常优先生气。有的来源用住户本人的吉方，有的用房子的吉方。
- **卧室：**宜在吉方；床头朝向睡者四个吉方之一。各来源选的星不同（延年、天医、伏位……），所以没有唯一“正确的星”。
- **书桌：**坐着时面向坐者的吉方，通常是生气。
- **神台：**设在吉方。有的来源只选伏位，有的允许四个吉方。
- **厨房：**常见说法是“坐凶向吉”，即灶设在凶方，灶口朝向吉方。但也有文章（如越南网站 CafeLand）认为这是误解，灶应设在吉方。
- **卫生间、储物间：**宜设在凶方，不占吉方。

## 理性看待八宅

八宅只是一个流派。其他流派，如玄空飞星，有自己的判断方法，结果可能不同。实际住宅还取决于采光、通风、安全和全家人的需要。如果某条风水建议与这些相冲突，应优先考虑实际情况。
